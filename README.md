# mathlua.github.io
MathLua (or Mathly) is a Lua module that turns Lua into a tiny, portable, free but powerful MATLAB and more. It provides some commonly used MATLAB functions and features, including convenient matrix operations, which makes coding and testing a thought much easier and faster than most other programming languages. Besides, it allows easy animation of 2D curves.

See [https://github.com/fdformula/mathly].
